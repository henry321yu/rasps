sudo nano /etc/systemd/system/lidar_lan_ras3.service

貼上內容如下："

[Unit]
Description=Start lidar_lan_ras3
After=network.target

[Service]
ExecStart=/usr/bin/python3 /home/raslan/Desktop/lidar_lan_ras3.py
WorkingDirectory=/home/raslan/Desktop
StandardOutput=inherit
StandardError=inherit
Restart=always
User=raslan
Environment=DISPLAY=:0
Environment=XAUTHORITY=/home/raslan/.Xauthority

[Install]
WantedBy=multi-user.target

"
啟用 service 服務
sudo systemctl daemon-reexec
sudo systemctl daemon-reload
啟用創建 的.service
sudo systemctl enable lidar_lan_ras3.service
立即啟動（選擇性）：
sudo systemctl start lidar_lan_ras3.service
OK

sudo systemctl disable lidar_lan_ras3.service

sudo systemctl daemon-reload

############ZEROTIER###############
先確保樹莓派系統是最新的：
sudo apt update
sudo apt upgrade -y

ZeroTier 官方提供 Linux 腳本安裝方式：
curl -s https://install.zerotier.com | sudo bash

可確認服務是否運行：
sudo systemctl status zerotier-one

加入 ZeroTier 網路
sudo zerotier-cli join d5e5fb653749492c

成功後可以用：
sudo zerotier-cli listnetworks

獲取分配的虛擬 IP：
ip addr show


# 查看加入的網路
sudo zerotier-cli listnetworks

# 查看節點 ID
sudo zerotier-cli info

# 離開某個網路
sudo zerotier-cli leave <network_id>
